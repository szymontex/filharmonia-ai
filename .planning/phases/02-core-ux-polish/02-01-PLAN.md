Create a snapshot-based undo/redo hook for Track arrays.

Interface:
```typescript
interface UndoRedoReturn {
  undo: () => void
  redo: () => void
  canUndo: boolean
  canRedo: boolean
  pushState: (tracks: Track[]) => void   // called before each mutation
  resetHistory: (tracks: Track[]) => void // called on file switch
}
```

Implementation details:
- State: `{ past: Track[][], present: Track[], future: Track[][] }`
- `pushState(newTracks)`: push current present to past (max 20 via `.slice(-19)`), set present to newTracks, clear future
- `undo()`: pop last from past into present, push current present to future. No-op if past empty
- `redo()`: pop first from future into present, push current present to past. No-op if future empty
- `resetHistory(tracks)`: clear past and future, set present to tracks (used on file switch)
- History persists across saves (Ctrl+S does NOT reset history) - per user decision
- Use `useState` for the history state, `useCallback` for all functions
- Import `Track` type from `useTrackEditor`
- Export `useUndoRedo` and `UndoRedoReturn`

  <name>Task 2: Create useKeyboardShortcuts hook</name>
  <files>frontend/src/hooks/useKeyboardShortcuts.ts</files>
  <action>
Create a global keyboard shortcut handler hook.

Interface:
```typescript
function useKeyboardShortcuts(handlers: Record<string, () => void>): void
```

Implementation details:
- Single `useEffect` with `keydown` listener on `document`
- Guard: skip if `e.target` is INPUT, TEXTAREA, or has `contentEditable` attribute
- Build combo string: `${e.ctrlKey || e.metaKey ? 'ctrl+' : ''}${e.shiftKey ? 'shift+' : ''}${e.key.toLowerCase()}`
  - Special case: space key should normalize to "space" (not " ")
  - `e.key === ' '` maps to `'space'`
- If combo matches a handler key, call `e.preventDefault()` then invoke handler
- Use `useRef` for handlers to avoid re-registering listener on every render (stable reference pattern):
  ```typescript
  const handlersRef = useRef(handlers)
  useEffect(() => { handlersRef.current = handlers })
  ```
  Then the keydown listener reads from `handlersRef.current`
- Single `useEffect` with empty deps (listener registered once)
- Export `useKeyboardShortcuts`
  </action>

  <done>useKeyboardShortcuts hook exists, registers single global keydown listener, skips INPUT/TEXTAREA, normalizes key combos, uses stable ref pattern</done>
