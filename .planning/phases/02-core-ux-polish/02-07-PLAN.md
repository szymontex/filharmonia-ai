The spacebar handler in CsvViewer.tsx (lines 560-567) only toggles player visibility. It needs to control actual playback.

**Problem:** StickyPlayer owns `isPlaying` state and `audioRef` internally (line 45: `const [isPlaying, setIsPlaying] = useState(false)`). CsvViewer has no way to tell StickyPlayer to play/pause.

**Solution:** Add a `togglePlayback` ref-based callback pattern:

1. In `useAudioPlayer.ts`:
   - Add `isPlaying: boolean` state
   - Add `setIsPlaying: (playing: boolean) => void` setter
   - Add `togglePlaybackRef: React.MutableRefObject<(() => void) | null>` — a ref that StickyPlayer will populate with its handlePlayPause function
   - Add `togglePlayback: () => void` callback that calls `togglePlaybackRef.current?.()`
   - Export all new members in UseAudioPlayerReturn interface

2. In `StickyPlayer.tsx`:
   - Accept new prop `onTogglePlaybackRef?: React.MutableRefObject<(() => void) | null>`
   - Accept new prop `onPlayingStateChange?: (isPlaying: boolean) => void`
   - In a useEffect, assign `handlePlayPause` to `onTogglePlaybackRef.current` on mount, null on cleanup
   - Call `onPlayingStateChange?.(isPlaying)` whenever `isPlaying` state changes (useEffect on isPlaying)

3. In `CsvViewer.tsx`:
   - Destructure `isPlaying`, `togglePlayback`, `togglePlaybackRef` from useAudioPlayer()
   - Pass `onTogglePlaybackRef={togglePlaybackRef}` and `onPlayingStateChange={setIsPlaying}` to StickyPlayer
   - Update spacebar handler:
     ```
     'space': () => {
       if (showPlayer) {
         togglePlayback()
       } else {
         togglePlayer()
       }
     }
     ```
   - Add `isPlaying`, `togglePlayback` to the useMemo dependency array

  NOTE: Do NOT use a simpler approach like lifting audioRef to the parent — StickyPlayer has complex internal audio state (waveform sync, time tracking) that depends on owning the audio element.
