<task type="auto">
  <name>Task 1: Integrate undo/redo and keyboard shortcuts into CsvViewer</name>
  <files>frontend/src/pages/CsvViewer.tsx, frontend/src/components/PlayerControls.tsx, frontend/src/components/TrackTable.tsx</files>
  <action>
1. **CsvViewer.tsx** -- Add undo/redo hook:
   - Import `useUndoRedo` and `useKeyboardShortcuts`
   - Initialize: `const undoRedo = useUndoRedo()`
   - When tracks are loaded from API (file switch), call `undoRedo.resetHistory(loadedTracks)`
   - Wrap all track mutations to push state before each change:
     - Find every call to trackEditor methods that modify tracks (updateClass, updateName, updateStart, updateStop, deleteTrack, mergeWithNext, cutSegmentAtTime, addSegmentAtTime, addSegmentBelow)
     - Before each mutation call, add `undoRedo.pushState(trackEditor.tracks)`
     - After undo/redo, sync: `trackEditor.setTracks(undoRedo.present)` and `trackEditor.setHasUnsavedChanges(true)`
     - The cleanest approach: create wrapper functions in CsvViewer that call pushState then the trackEditor method

2. **CsvViewer.tsx** -- Wire keyboard shortcuts:
   - Define class order: `const CLASS_ORDER = ['MUSIC', 'APPLAUSE', 'SPEECH', 'PUBLIC', 'TUNING'] as const`
   - Call `useKeyboardShortcuts` with handler map:
     - `'space'`: toggle player (call `audioPlayer.togglePlayer()` or play/pause if player is open)
     - `'ctrl+s'`: call `autosave.manualSave()`
     - `'ctrl+z'`: call `undoRedo.undo()`, then sync tracks
     - `'ctrl+shift+z'`: call `undoRedo.redo()`, then sync tracks
     - `'ctrl+y'`: call `undoRedo.redo()`, then sync tracks (alternative binding)
     - `'1'` through `'5'`: if `audioPlayer.selectedTrackId` exists, call the wrapped `updateClass` with `CLASS_ORDER[keyNum-1]`
   - Use `useMemo` or `useCallback` for the handlers object to avoid unnecessary re-renders

3. **PlayerControls.tsx** -- Add undo/redo buttons:
   - Accept new props: `onUndo: () => void`, `onRedo: () => void`, `canUndo: boolean`, `canRedo: boolean`
   - Add undo (arrow-left or undo icon) and redo (arrow-right or redo icon) buttons near save/discard
   - Buttons disabled when `!canUndo` / `!canRedo` (opacity-50 cursor-not-allowed)
   - Tooltip text: "Undo (Ctrl+Z)" and "Redo (Ctrl+Shift+Z)"

4. **TrackTable.tsx** -- Add selected track visual indicator:
   - Accept new prop: `selectedTrackId: string | null`
   - Highlight the row matching `selectedTrackId` with a distinct background (e.g., `bg-blue-50` or ring outline)
   - This helps users see which track number keys 1-5 will affect
