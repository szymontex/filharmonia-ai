  <files>frontend/src/stores/toastStore.ts, frontend/src/components/ToastContainer.tsx, frontend/src/components/Toast.tsx</files>
  <action>
1. Create `frontend/src/stores/toastStore.ts`:
```typescript
import { create } from 'zustand'

interface ToastItem {
  id: string
  title: string
  message?: string
  color: 'green' | 'red' | 'blue' | 'yellow' | 'purple'
  icon?: string
  retry?: () => void
}

interface ToastStore {
  toasts: ToastItem[]
  addToast: (toast: Omit<ToastItem, 'id'>) => void
  removeToast: (id: string) => void
  clearAll: () => void
}
```
- `addToast`: generate UUID-style id (`Date.now().toString(36) + Math.random().toString(36).slice(2)`), append to toasts, cap at 5 (remove oldest if exceeded)
- `removeToast`: filter out by id
- `clearAll`: set toasts to empty array
- Export as `useToastStore`

2. Create `frontend/src/components/ToastContainer.tsx`:
- Import `useToastStore` and the existing `Toast` component
- Render toasts from store, passing `index` for stacking, `onClose` calls `removeToast`
- For error toasts (color='red'): do NOT pass `autoClose` (user must dismiss manually)
- For success toasts (color='green'): pass `autoClose={5000}`
- Mount this component once in the app root (App.tsx or layout)

3. Enhance existing `Toast.tsx`:
- Add an explicit X close button (top-right corner) in ADDITION to click-to-dismiss
- The X button calls `onClose`, shown on all toasts (with or without actions)
- If toast has `retry` action, show a "Retry" button in the actions area

<task type="auto">
  <name>Task 2: Create axios error interceptor and add backend error codes</name>
  <files>frontend/src/utils/errorHandler.ts, backend/app/main.py</files>
  <action>
1. Create `frontend/src/utils/errorHandler.ts`:
- Export `setupErrorInterceptor()` function
- Registers axios response interceptor:
  - On error, check `error.response?.data`
  - If `data.status === 'error'`: dispatch toast via `useToastStore.getState().addToast({...})`
    - title: `data.message || 'An error occurred'`
    - message: `data.error_id ? 'Error ID: ' + data.error_id : data.code || undefined`
    - color: 'red'
    - icon: 'X' (unicode cross mark)
    - retry: for GET requests only, `() => axios(error.config)`
  - Always `return Promise.reject(error)` so callers can still handle errors locally
- Call `setupErrorInterceptor()` once at app startup (in main.tsx or App.tsx)

2. Update `backend/app/main.py` exception handlers to include `code` field:
- `http_exception_handler`: add `"code": "HTTP_{exc.status_code}"` to response dict (e.g., "HTTP_404", "HTTP_403")
- `validation_exception_handler`: add `"code": "VALIDATION_ERROR"` to response dict
- `global_exception_handler`: add `"code": "INTERNAL_ERROR"` to response dict
- Do NOT change existing fields -- only ADD the `code` field
  </action>
