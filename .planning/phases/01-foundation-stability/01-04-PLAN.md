<objective>
Replace hardcoded `/tmp/` paths with cross-platform `tempfile.gettempdir()`.

Purpose: Hardcoded `/tmp/` only works on Unix systems. Windows uses `C:\Users\...\AppData\Local\Temp`. Using `tempfile.gettempdir()` ensures the application works on all platforms.

Output: Three backend files using cross-platform temporary directories.
</objective>

<task type="auto">
  <name>Task 1: Fix temp directory in analyze.py</name>
  <files>
    backend/app/api/v1/analyze.py
  </files>
  <action>
Replace hardcoded `/tmp/filharmonia_jobs` with cross-platform alternative.

1. Add import at top of file:
```python
import tempfile
```

2. Replace lines 15-16:
```python
# Old:
JOBS_DIR = Path("/tmp/filharmonia_jobs")
JOBS_DIR.mkdir(exist_ok=True)

# New:
JOBS_DIR = Path(tempfile.gettempdir()) / "filharmonia_jobs"
JOBS_DIR.mkdir(exist_ok=True)
```

This change:
- On Linux: Uses `/tmp/filharmonia_jobs` (same as before)
- On Windows: Uses `C:\Users\<user>\AppData\Local\Temp\filharmonia_jobs`
- On macOS: Uses `/var/folders/.../filharmonia_jobs` or `/tmp/filharmonia_jobs`
- Respects TMPDIR/TEMP environment variables if set
