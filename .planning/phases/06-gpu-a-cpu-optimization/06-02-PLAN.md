  <files>backend/app/services/ast_inference.py</files>
  <action>
In `ast_inference.py`, modify `load_model()` to apply torch.compile conditionally:

1. After `self.model.eval()` and `self.model.to(self.device)`, check `self.device_manager.supports_compile`
2. If supports_compile is True:
   a. Log: "Applying torch.compile for GPU acceleration"
   b. Run a warmup inference BEFORE compiling to get eager baseline time:
      - Create dummy input: `torch.randn(1, 1024, 128).to(self.device)`
      - Time 3 eager inference calls with `torch.cuda.synchronize()`, take average
   c. Apply `self.model = torch.compile(self.model, mode="default")`
   d. Run warmup inference to trigger compilation (3 calls, time average)
   e. Log benchmark: `"torch.compile speedup: {eager_ms:.1f}ms -> {compiled_ms:.1f}ms ({speedup:.1f}x)"`
3. If supports_compile is False:
   a. Log: "Skipping torch.compile on CPU"

Use `time.perf_counter()` for timing. Import `time` at top.

For graph break debugging, add before compile:
```python
import torch._logging
torch._logging.set_logs(graph_breaks=True)
```

Wrap the entire torch.compile block in try/except. If compilation fails (e.g., unsupported op), log warning and continue with eager mode. Do NOT crash the server.

Do NOT change predict_segment or predict_batch logic.
  </action>

`grep -n "torch.compile" backend/app/services/ast_inference.py` shows the compile call.
`grep -n "warmup" backend/app/services/ast_inference.py` shows warmup logic.
Server starts without error on CPU (torch.compile should be skipped).
  </verify>
