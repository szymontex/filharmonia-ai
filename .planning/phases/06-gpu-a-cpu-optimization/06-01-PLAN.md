<task type="auto">
  <name>Task 1: Create DeviceManager with CUDA/ROCm/CPU detection</name>
  <files>backend/app/core/device_manager.py</files>
  <action>
Create `backend/app/core/device_manager.py` with a `DeviceManager` class and `get_device_manager()` singleton factory.

DeviceManager must:
1. Detect device once in `detect_device()` method:
   - Check `torch.cuda.is_available()`
   - If CUDA available, check `torch.version.hip` for AMD ROCm vs `torch.version.cuda` for NVIDIA
   - Set `self.device` (torch.device), `self.device_type` (string: "cuda_nvidia", "cuda_amd", "cpu"), `self.device_name` (GPU name string or "CPU")
2. Log detailed info using Python `logging` module:
   - GPU: device type, device name, CUDA/ROCm version, device count
   - CPU: warning that no GPU detected
3. Support fallback: if GPU init fails (e.g., driver issue), catch exception, log error, fall back to CPU
4. Expose `is_gpu` property (bool) and `supports_compile` property (bool — True for GPU only)

`get_device_manager()` returns singleton, creates + calls `detect_device()` on first call.

Use `logging.getLogger(__name__)` not print statements.
  </action>
  <verify>
`python -c "from app.core.device_manager import get_device_manager; dm = get_device_manager(); print(dm.device_type, dm.device)"` runs without error from backend directory.
  </verify>
  <done>DeviceManager singleton detects and logs device type at startup. Properties expose device info for downstream consumers.</done>
</task>

Do NOT change any inference logic, preprocessing, or prediction methods. Only change device detection and logging.
