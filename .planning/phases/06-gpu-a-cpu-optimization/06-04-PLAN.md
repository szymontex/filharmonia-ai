  <action>
Enhance DeviceManager (created in 06-01) with ROCm-specific logic:

1. When `device_type == "cuda_amd"`, add a ROCm validation step after detection:
   a. Run a quick GPU operation: `torch.randn(10, 10, device='cuda') @ torch.randn(10, 10, device='cuda')`
   b. Time it. If it takes >100ms for this trivial op, log WARNING about potential silent CPU fallback
   c. Check `torch.cuda.get_device_properties(0)` for total memory — log it for debugging
   d. Log ROCm version: `torch.version.hip`

2. Add method `validate_gpu_performance()` that:
   a. Runs a larger matmul (256x256) on GPU, times it
   b. Runs same on CPU, times it
   c. If GPU is slower than CPU, log CRITICAL warning: "ROCm may be falling back to CPU silently"
   d. Returns bool (True if GPU performing normally)

3. Call `validate_gpu_performance()` during `detect_device()` when ROCm is detected

4. Ensure all ROCm-specific code is wrapped in try/except with CPU fallback

5. Add `rocm_version` property that returns `torch.version.hip` or None
