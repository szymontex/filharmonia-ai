<task type="auto">
  <name>Task 1: Confidence threshold learner and hook</name>
  <files>frontend/src/utils/confidenceThreshold.ts, frontend/src/hooks/useConfidenceAdjust.ts</files>
  <action>
**confidenceThreshold.ts:** Create `ConfidenceThresholdLearner` class:
1. Stores per-recording thresholds in a Map<string, RecordingThreshold>
2. Interface RecordingThreshold: { recordingId: string, threshold: number, falsePositives: number, falseNegatives: number, corrections: number }
3. `getThreshold(recordingId)` - returns current threshold or DEFAULT_THRESHOLD (0.7)
4. `recordCorrection(recordingId, type: 'delete' | 'add')`:
   - 'delete' (user removed a prediction = false positive) → raise threshold by LEARNING_RATE (0.05)
   - 'add' (user added a label = false negative) → lower threshold by LEARNING_RATE (0.05)
   - Clamp to [0.3, 0.95] range
5. `persist()` - save to localStorage key "filharmonia_thresholds"
6. `load()` - restore from localStorage on construction
7. Singleton export: `const thresholdLearner = new ConfidenceThresholdLearner()`

**useConfidenceAdjust.ts:** Create React hook:
1. Takes `recordingId: string` parameter
2. Returns `{ threshold: number, recordCorrection: (type: 'delete' | 'add') => void }`
3. Uses the singleton `thresholdLearner` internally
4. On `recordCorrection`, calls learner and triggers re-render via useState

NOTE: This hook provides the threshold value. Integration with the existing confidence threshold slider in PlayerControls (which currently uses a hardcoded default) will be wired in this task:
- In CsvViewer.tsx, use `useConfidenceAdjust` to get the threshold for the current recording
- Pass this threshold as the initial value for the threshold slider
- When user manually adjusts slider, that overrides the auto-tuned value for the session
