<task type="auto">
  <name>Task 2: Fix regex recompilation (PERF-03)</name>
  <files>backend/app/api/v1/files.py</files>
  <action>
Fix the regex recompilation issue at line 90 in `list_analysis_results()`.

Current code (line 90):
```python
match = re.search(r'_(\d{4})-(\d{2})-(\d{2})', csv_file.name)
```

Fix: Add a module-level compiled pattern near the top of the file (after imports, around line 17):
```python
# Pre-compiled regex patterns for performance (PERF-03)
DATE_PATTERN = re.compile(r'_(\d{4})-(\d{2})-(\d{2})')
```

Then replace line 90 with:
```python
match = DATE_PATTERN.search(csv_file.name)
```

Why: Python's re module caches compiled patterns but only up to 512 patterns. Module-level compilation is clearer and guarantees no recompilation per iteration.
  </action>
